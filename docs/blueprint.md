# **App Name**: Kira Aesthetic

## Core Features:

- Multi-Language Support: Enable content localization for English, Spanish, German, French, Italian, and Albanian.
- Service Directory: Categorized listing of all aesthetic, dental, and medical treatments offered.
- Admin Panel for Blog Management: Secure admin interface for managing blog content and updates.
- Contact Form with Submission Handling: Allow prospective clients to send questions directly through the site, handled by backend logic.
- Image Gallery: A collection of photographs (before-and-after, office space etc.)
- AI-Powered Chatbot: Employ an AI chatbot tool for immediate response to FAQs and initial consultations using data provided through the backend.
- Customer Feedback Repository: The app maintains customer feedback about their treatment experience

## Style Guidelines:

- Primary color: Deep Forest Green (#41A340) for elegance and trust.
- Secondary color: Darker shade of Forest Green (#2E732B) for subdued emphasis.
- Accent color: Bright Orange (#E67E22) for energetic call-to-actions.
- Background color: Very light cream (#FFFDF7) for a soft, warm base.
- Body and headline font: 'PT Sans' (sans-serif) for clean, modern readability.
- Consistent use of lucide-react icons for a modern and unified feel.
- Responsive container with a max-width of 1400px to center content effectively.
